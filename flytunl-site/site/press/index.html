Boilerplate

Short (one line)

TUNL is a hold-to-thrust cave flyer for iOS, Android and the web where every player on Earth flies the exact same procedurally-generated cave each day.

Long (two paragraphs)

TUNL is a one-tap arcade flyer: hold to thrust up, release to fall, thread a narrowing cave while dodging stalactites, mines, and wall-mounted cannons. Coins widen the tunnel and unlock power-ups - a shield, a magnet, bullet time - so surviving deeper is a skill loop, not just a longer wait.

The catch is that the cave itself is seeded from the calendar date, so every player, on every platform, flies the identical corridor on a given day - the same near-miss, the same lucky coin run, the same wall that ends it. A daily leaderboard, a beatable ghost of the day's best run, and a one-tap share card turn that shared cave into something worth comparing notes on, not just a personal best to chase alone.
