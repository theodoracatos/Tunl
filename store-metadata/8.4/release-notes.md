# TUNL 8.4 - Release notes (16 locales)

Theme: the two-sided referral reward (invite a friend, earn 20 shards once their first
real run clears the bar) + Universal Links / App Links, so a shared run link now opens
straight into the app for a friend who already has TUNL, instead of the browser. Also
ships a store-rating prompt on a new all-time best, not called out in the copy below
(kept the public message to the two player-facing hooks). All entries under Google
Play's 500-char/locale limit. en/de/fr/it/es/pt/ja reuse the flytunl.ch "New in 8.4"
homepage banner copy (`flytunl-site/i18n/home.json` hero.newBody) so the site and both
stores say the same thing; pt-BR reuses pt per the 8.3 convention.

---
