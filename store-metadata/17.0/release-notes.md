# TUNL 17.0 - Play Console / App Store Connect "What's New" copy (15 locales)

What's new this release: a hangar paint kit (hull colour x pattern x material x effect,
combined per ship, replacing the six fixed liveries), the ship's streak and stardust made
visible (always-on wallet, a path to the next ship, a shard bonus for a full week, a rest
day that absorbs one missed day), and a new F-14-style silhouette with wings that fold
back for a warp and spread for a blue coin.

Deliberately NOT in the copy: point values or exact percentages (qualitative only,
feedback_marketing_no_stat_numbers) and pixel/dB numbers. No em dashes.

Versions: iOS marketing 17.0 / build 57, Android versionName 17.0 / versionCode 51.
Store assets: none new (icon/wordmark still the SR-71 mark by the user's choice, unrelated
to the in-flight F-14 hull).

**ASC / Play status**: not yet submitted. Paste What's New into both consoles for the
17.0 build once it's uploaded.
