SCOREFORMAT / SCOREFORMATSUFFIX (Play Console leaderboard settings)

Scoreformat:            Numerisch (Numeric)
  Dezimalstellen:       0
  -> the in-game score is floor(scrollX/60) + bonusScore, a plain integer
     ("SCORE: 1234"). Not currency, not a time.

Scoreformatsuffix:      leave EMPTY (both Singular and Plural)
  -> the game never labels the number with a unit. Matches the iOS Game
     Center board (no suffix there either), so the two platforms read the
     same. If a suffix is ever wanted, use "pt" / "pts" (or per-locale
     Punkt/Punkte, point/points, etc.) - but empty is the cleaner default.
