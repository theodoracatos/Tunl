# TUNL High Score - leaderboard description (15 locales)

Leaderboard: `tunl_highscore` (daily, resets at midnight UTC) - display name
"TUNL High Score".

Note: neither App Store Connect Game Center nor Play Games Services has a
per-locale *description* field for a leaderboard (only a display name + score
format). This copy is for the places that do take descriptive text - the
Game Center Challenge slot, the marketing site's leaderboard section, Play
Console's "additional details", press/store notes - kept parallel with the
15 in-game locales (`LANG_ORDER` in `src/i18n.js`).

Voice: the daily-seed hook (everyone flies the identical cave) + the one-line
control model + the daily reset.

---

## en
Everyone on Earth flies the exact same cave each day - same walls, same coins, seeded from today's date. Hold to climb, release to fall, and see how far you get before the tunnel closes in. Resets daily at midnight UTC.
