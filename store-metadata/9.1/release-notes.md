# TUNL 9.1 - Release notes + promotional text (16 locales)

Theme: Eight new Game Center / Play Games achievements built on 9.0's 7-day rock-world
rotation - one "flew this world" badge for finishing a real run (score >= 25) on each of
the seven daily worlds (Ceres, Mars, Luna, Io, Ianthe, Pallas, Rhodia), plus a Grand
Tour capstone for collecting all seven. Not mentioned in the public copy: the WORLD
number now counts up monotonically from a fixed epoch instead of resetting each Jan 1
(invisible to players beyond the number no longer repeating). All entries well under
Google Play's 500-char/locale limit. pt-BR reuses pt per the 8.3/8.4/9.0 convention.
No em dashes anywhere (project rule); accented characters are fine and used normally.

Two sections below: **What's New** (version-specific, both stores) and **Promotional
Text** (App Store Connect "Werbetexte" only - Google Play has no equivalent field).
Promo text is evergreen tagline copy, not tied to 9.1 specifically, so it does not need
rewriting every release the way What's New does - only touch it again if the pitch
itself needs to change. Both sections filled in ASC for all 16 iOS locales as of 9.1
(2026-09-07); Werbetexte was empty pre-9.1, this is its first draft.
